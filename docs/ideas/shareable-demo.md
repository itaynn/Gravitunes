# Shareable demo file

**Status:** idea

## What it is
A "Download this demo" button that builds one self-contained HTML file (code + small value grids inlined, ~2 MB) from any mode and dataset.

## Notes
- Works by double-click on computers. On phones a local HTML file usually can't play sound (iOS previews don't run JavaScript), so for phones put the same file at a link (e.g. a Claude artifact or any one-file host).
- Generated from the shared code, so it never drifts from the app.
- Always needs a "Start sound" button (browser autoplay rule).
