# The Earth Information Jukebox: Resources

Source: [2026 NASA Space Apps Challenge — Resources](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=resources)  
Retrieved: 2026-11-14

## NASA data and examples

| Resource | Link | How it may help |
|---|---|---|
| Earth Information Center (EIC) Content Database | [NASA Scientific Visualization Studio gallery](https://svs.gsfc.nasa.gov/gallery/earth-information-center/) | Visuals used in EIC dashboards; videos and images can be used as input for audio processing. |
| Data Sonification: Caldwell 73 | [NASA SVS 13786](https://svs.gsfc.nasa.gov/13786/) | A space-imagery sonification example illustrating how visual properties such as luminosity and spatial coordinates can inform volume and pitch. |
| Change in Night Lights between 2012 and 2023 — EIC Version | [NASA SVS 5313](https://svs.gsfc.nasa.gov/5313/) | High-contrast views of changing urban illumination; useful for exploring mappings from intensity to tempo or volume. |
| Global Sea Surface Currents and Temperature | [NASA SVS 3912](https://svs.gsfc.nasa.gov/3912/#media_group_349716) | Current and temperature animations for experiments with motion and changing values as evolving sound. |
| GEOS Aerosols | [NASA SVS 5669](https://svs.gsfc.nasa.gov/5669/) | Visualizes smoke, dust, and other particle types; layers could be assigned distinct audio textures or instruments. |
| Air Quality Model Runs | [NASA SVS 5533](https://svs.gsfc.nasa.gov/5533/) | Downloadable high-resolution atmospheric model frames that can be analyzed for color and pixel density. |
| Perpetual Ocean 2: Western Boundary Currents | [NASA SVS 5425](https://svs.gsfc.nasa.gov/5425/) | Maps of major ocean boundary currents; visual changes can be explored as rhythms or scales. |
| DYAMOND Global Carbon Dioxide | [NASA SVS 5196](https://svs.gsfc.nasa.gov/5196/) | Changing global CO₂ patterns that can drive interactive audio synthesis. |
| Lightning Events Detected from the ISS 2017–2023 | [NASA SVS 5011](https://svs.gsfc.nasa.gov/5011/) | Layered lightning observations that could inspire percussive sounds or audio triggers tied to flashes. |
| A 3D View of an Atmospheric River from an Earth System Model | [NASA SVS 4960](https://svs.gsfc.nasa.gov/4960/) | A 3D atmospheric-river visualization for exploring frame-by-frame mappings of moisture density and spread. |
| GEDI Forest Height | [NASA SVS 4950](https://svs.gsfc.nasa.gov/4950/) | Global canopy elevation maps that can inform mappings from forest height and density to rhythm, frequency, or pitch. |

## Use notice

NASA states that it does not endorse non-U.S. Government entities and is not responsible for information on non-U.S. Government websites. Participants must follow the data-use terms of any non-U.S. Government website they use.

The challenge page says that additional resources may be added before the hackathon. Check the [live Resources tab](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=resources) for updates and consult each source for its current availability and usage terms.
