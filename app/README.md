# app: the Gravitunes front end

Serve from the repo root (`python3 -m http.server 8000`) and open `http://localhost:8000/app/`.

- `core/`: the shared viewer (base map plus frames), timeline, hover/click/keyboard input converted to lat/lon, the side panel, and screen-reader announcements.
- `modes/`: one folder per idea. The gallery lists them automatically from `modes/index.json`, which is regenerated by a script, so nobody edits a shared menu.

## Add a mode
1. Copy `modes/_template/` to `modes/<your-mode>/`.
2. Edit `mode.json` (name, author, description, datasets).
3. Write `main.js`:
   ```js
   export default function start(ctx) {
     // ctx.dataset  values, valueAt(lat, lon, t), units, color bar
     // ctx.viewer   the map, overlays, lat/lon <-> pixel conversion
     // ctx.time     play/pause/scrub, onFrame(t)
     // ctx.input    hover/click/keys, as lat/lon
     // ctx.sound    the sound engine (see sound-engine/)
     // ctx.panel    add labeled controls
     // ctx.describe(text)  screen-reader announcement
     return () => {};   // cleanup when the mode is closed
   }
   ```
   **Escape hatch:** a mode can be a plain `index.html` instead of `main.js`, and the gallery just links to it.
4. If it needs offline analysis, put the script in `analysis/scripts/<your-mode>/`. Have it write small outputs to `modes/<your-mode>/data/`.

Rules: modes don't import each other. Shared code goes into `core/`.

## Basemap
The viewer draws faint coastlines and country borders (`data/earth/coastlines.json`, `borders.json`) between the data image and mode overlays. Toggle: the "Coastlines and borders" checkbox, `?basemap=0`, or `viewer.setBasemap(false)`. Rebuild with `data-tools/natural_earth.py`.

Credits: coastlines and borders from [Natural Earth](https://www.naturalearthdata.com/), public domain.
